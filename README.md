現在YoutubeMusicリンクの対応がまだできてません

Botで使えるコマンドの一覧です。
※プレフィックスはデフォルトの t! で記載しています。

t!play <URL> (または t!p)
音楽やプレイリストを再生・キューに追加

t!stop (または t!s)
再生を停止し、Botを退出させる

t!next (または t!n)
現在の曲をスキップする

t!loop (または t!l)
現在の曲をループ（1曲リピート）に設定する

t!loopplay <URL> (または t!lp)
最初からループ指定で曲を再生・追加する

t!queue (または t!q)
再生待ちリスト（最大10件）を表示する

t!delete <番号> (または t!d / t!remove / t!rm)
指定した番号の曲を再生待ちリストから削除する
